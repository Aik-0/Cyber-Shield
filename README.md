Cyber Shield AI

A bilingual (Arabic/English) system that analyzes phone calls to detect potential scams using audio recording and speech recognition.

Features

SHA-256 phone number hashing.

Audio recording and speech-to-text analysis.

Suspicious keyword detection and risk assessment.

Bilingual web interface.

Technologies
Python, Flask, HTML, CSS, JavaScript, SoundDevice, SpeechRecognition.

Installation
pip install Flask numpy sounddevice SpeechRecognition
